# ALuncher

Minecraft Java Edition의 실행 환경과 모드를 한곳에서 관리하는 Windows 런처입니다.

이 저장소는 ALuncher 설치 파일과 변경 내용을 제공하기 위한 배포 공간입니다. 공개 배포 파일은 아직 없습니다.

배포가 준비되면 Releases에서 버전별 Windows 설치 파일, 변경 내용, 파일 확인 정보를 제공할 예정입니다. 업데이트는 적용 전에 사용자 승인을 받습니다. 제거 시 게임 데이터·설정·백업은 보존합니다.

자세한 배포 기준은 [배포 정책](POLICY.md)을 확인해 주세요.

ALuncher는 Mojang 또는 Microsoft의 공식 제품이 아닙니다. Minecraft는 해당 소유자의 상표입니다.
