# ALuncher

Minecraft Java Edition의 실행 환경과 콘텐츠를 관리하는 Windows 런처의 공식 배포 저장소입니다.

[0.2.5 개발 미리보기 다운로드](https://github.com/illililiiililii/ALuncher-Releases/releases/tag/v0.2.5) · [전체 릴리스](https://github.com/illililiiililii/ALuncher-Releases/releases) · [선별 공개 소스](https://github.com/illililiiililii/ALuncher)

실행 파일·설치 파일·변경 내용·서명된 업데이트 안내를 제공합니다. 개발 미리보기는 정식 자동 업데이트로 승격하지 않습니다. 런처의 ‘개발 미리보기도 확인’을 명시 선택하면 조회할 수 있습니다. 적용 전 검토·승인을 유지하고 제거 시 게임 데이터·설정·백업을 보존합니다.

0.2.5는 저장 공간의 긴 경로/카드/막대 UI 수정과 선택 정리 미리보기, 리소스팩·셰이더 최초 자동 탐색/정렬, 설정 검색을 포함합니다. 전체 로드맵이나 실제 게임·새 Windows/동일제품 설치 검증이 완료된 정식 제품이라는 의미가 아닙니다. 검증/남은 범위는 각 릴리스 노트를 확인하세요.

0.2.5 새 고유 코드/변경분부터 [ALuncher Personal Use License](https://github.com/illililiiililii/ALuncher/blob/main/LICENSE)를 적용합니다. 개인 무료 사용과 개인화는 허용하며 런처 자체 수정·업데이트 제작·원본/수정본 재배포는 GitHub illililiiililii의 사전 명시 허락이 필요합니다. 기존 MIT 사본/부분의 권한과 서드파티 권리는 유지됩니다. 원본 개발 이력은 비공개 AllLauncher에서 보존하고 공개 소스는 독립 이력의 선별 snapshot입니다.
